# E-Cart – E-Commerce Shopping Platform

## 📌 Project Overview

E-Cart is an online shopping platform developed using Python Flask. It allows customers to browse products, add items to their shopping cart, manage wishlists, and place orders. It also provides an admin panel to manage products and customer orders.

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Backend:** Python, Flask
- **Version Control:** Git and GitHub

## ✨ Features

### 👤 Customer Module
- Customer registration and login
- Browse and search products
- Filter products by category
- Add products to shopping cart
- Update and remove cart items
- Add and remove wishlist products
- Checkout and place orders
- View purchase history
- Track order status
- Cancel eligible orders

### 🔐 Admin Module
- Admin login
- Admin dashboard
- Add new products
- Edit existing products
- Delete products
- Search and filter products
- View customer orders
- Update order status

## ⚙️ Installation and Setup

### Step 1: Clone the Repository

```bash
git clone https://github.com/gogulasushma/e-cart-shopping-platform.git
```

### Step 2: Open the Project Folder

```bash
cd e-cart-shopping-platform
```

### Step 3: Install Required Packages

```bash
pip install -r requirements.txt
```

### Step 4: Run the Application

```bash
python app.py
```

### Step 5: Open in Browser

```text
http://127.0.0.1:5000/
```
